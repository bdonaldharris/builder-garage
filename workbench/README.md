# Workbench

Reusable skills, workflows, tools, and engineering procedures live at the Workbench.

## Current canonical artifacts

Engineering skills currently remain in [`../skills/`](../skills/) to preserve existing installation paths, references, and invocation contracts. This shop area organizes how those procedures are discovered and used; it does not duplicate their authoritative contents.

Follow the canonical skill contracts, not a summary here.

## Boundary

The Workbench owns *how* engineering work is done. It does not decide who performs the work ([Crew](../crew/)), whether the result is correct ([Inspection](../inspection/)), or how accepted work is integrated and promoted ([Shipping](../shipping/)).

## Status

This directory contains documentation only. The Workbench's content today is the set of skills listed above; no tooling has been implemented. See the [architectural direction](../docs/architecture.md).
